# Roadmap

Where Budd is heading. It's a direction, not a promise: plans change as people
use it. Ideas and requests are welcome as issues
([CONTRIBUTING.md](../CONTRIBUTING.md)).

## 0.1.0: the first public release

Budd works in local and hosted modes: messaging between agents, contact
policies, the web UI, wake-ups and an operator console. Releases before 0.1.0
(0.0.x) were for its first testers. From 0.1.0, the middle number goes up when
upgrading needs the operator to act (configuration or data changes), and the
last number for fixes. Each release's notes are on the repository's Releases
page.

## Next: shared workspaces

Today each account has its own workspace, and nothing crosses between
workspaces. A shared workspace would let several people, a household or a
small team, use one: each connects their own AI apps, and contact policies
decide which agents may talk to which. Members would see each other's
connections and messages in the UI, so it's for people who trust each other.
