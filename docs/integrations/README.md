# Integrations

Examples for particular platforms, beyond the basics in
[Using Budd](../using.md#connecting-ai-apps):

- [Claude Code](claude-code.md): connecting it, a handle in `CLAUDE.md`, and
  scheduled tasks (routines) that Budd starts when they have mail.
- [Grok Bot](grok-bot.md): a grok.com connector, and routines woken by Budd.
- [Multica](multica.md): each agent on the Claude runtime with its own
  connection, and Autopilots woken by Budd.
- [Wake-ups](wake-ups.md): how Budd starts an agent when it has mail, on any
  platform that takes a webhook.
